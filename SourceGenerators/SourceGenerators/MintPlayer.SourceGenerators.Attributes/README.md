# MintPlayer.SourceGenerators.Attributes

Attribute definitions for [MintPlayer.SourceGenerators](https://github.com/MintPlayer/MintPlayer.Dotnet.Tools/blob/master/SourceGenerators/SourceGenerators/MintPlayer.SourceGenerators/README.md), the generator that generates service registrations and constructor-free injection.

You normally do not reference this package directly - referencing `MintPlayer.SourceGenerators` brings it along.
It is published separately so a project can declare the attributes without taking the generator
with it, for example a shared contracts assembly consumed by several projects.
