# MintPlayer.Mapper.Attributes

Attribute definitions for [MintPlayer.Mapper](https://github.com/MintPlayer/MintPlayer.Dotnet.Tools/blob/master/SourceGenerators/Mapper/MintPlayer.Mapper/README.md), the generator that generates mapper extension methods.

You normally do not reference this package directly - referencing `MintPlayer.Mapper` brings it along.
It is published separately so a project can declare the attributes without taking the generator
with it, for example a shared contracts assembly consumed by several projects.
