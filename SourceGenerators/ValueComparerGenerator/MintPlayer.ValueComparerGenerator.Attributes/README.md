# MintPlayer.ValueComparerGenerator.Attributes

Attribute definitions for [MintPlayer.ValueComparerGenerator](https://github.com/MintPlayer/MintPlayer.Dotnet.Tools/blob/master/SourceGenerators/ValueComparerGenerator/MintPlayer.ValueComparerGenerator/README.md), the generator that generates value-comparers for incremental generator models.

You normally do not reference this package directly - referencing `MintPlayer.ValueComparerGenerator` brings it along.
It is published separately so a project can declare the attributes without taking the generator
with it, for example a shared contracts assembly consumed by several projects.
